# 0.5.0 — portable daily-workchat integration

Adds a local cross-chat workflow adapter, four MCP tools, a CLI fallback, an explicit
installer, and tests for scope, evidence integrity and preserved configuration.
The original 0.4.0 experimental source and captured model results are unchanged.

The release contains reusable code and documentation, not the author's private bank,
chat IDs, saved work lessons, credentials or global application configuration.
No new model calls are made by tests or captured-evidence replay. Cloud/web/mobile
chat connectivity is not supplied by this local adapter.
