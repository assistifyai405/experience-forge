# Attribution and claim boundaries

Experience Forge contributes an authored synthetic connector environment, typed durable experience storage, independent candidate qualification, explicit observed-use metrics, execution checks, a controlled pilot and replayable evidence. The affine functional form and exact arithmetic helper are supplied by the harness; they are not functions invented or trained into a model.

Code and documentation were developed with OpenAI Codex assistance. The actual evaluated tool agent used the independently developed **Qwen3.5** model through **Ollama**, not an OpenAI model or the paid Jev service. No affiliation, endorsement or adoption by OpenAI, Qwen, Ollama or TypeSafe is claimed.

Primary sources:

- [Qwen3.5-4B official model card](https://huggingface.co/Qwen/Qwen3.5-4B): model provenance; the card lists Apache-2.0 for its model artifacts. This project does not redistribute model weights.
- [Ollama qwen3.5:4b model entry](https://ollama.com/library/qwen3.5:4b) and [Ollama source](https://github.com/ollama/ollama): runtime/model distribution. The reported installed artifact digest and runtime version are preserved in the pilot evidence.
- [TypeSafe documentation](https://docs.typesafe.ai/): Jev supplied one separately authorized paid, typed design review, not live benchmark inference or a generated build prompt. Its three answers and token usage are retained separately.
- [GitHub secure-use guidance](https://docs.github.com/en/actions/reference/security/secure-use): CI actions are pinned to verified full commit hashes and receive only read permission.

The application code is distributed under the existing [MIT license](../LICENSE). Third-party runtimes, model artifacts and services retain their own terms. No third-party source tree or model weights are vendored here.

This is an authored pilot with supplied mathematical structure and unequal information availability by design. It does not demonstrate general intelligence, updated model weights, independent external replication or a validation-quality advantage in final completion. See the full protocol and retained failures before interpreting the result.
